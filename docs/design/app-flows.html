Variance app flows

How a designer takes a folder of SVG icons to a shipped variable font: the flows, the objects, the screens, and the tools for the part no rule can do.

Builds on the research thread's manual-fix brief and research 01–08. Markdown source: docs/design/app-flows.md.

  • Variance is a token system for icon geometry. The set's style rule is the global tier, edge contexts are the semantic tier, and per-part settings are the component tier. A manual fix is a component override the rule never overwrites.
  • One loop, six stages: import, choose a style, generate, triage, fix, export. A seventh, teach the rule, feeds fixes back so later icons need fewer.
  • The review queue is the home screen. The rule alone reaches 76% / 64% of Google's edges; fitted settings reach 94% / 89%. The queue ranks icons by risk and says why, so designers look at the worst 10–20%.
  • Fit to a drawing is the headline tool. Draw one master by hand once; Variance turns it into settings on the source.
  • Nine open decisions at the end. The biggest: where the app runs.

Token tiers for geometry

The research already has three layers of settings. Naming them as tiers gives designers a model they know from colour and spacing tokens. A lower tier wins; the inspector shows each value's resolved source, the way Figma shows a variable's alias chain.

GlobalStyle rule. "Pen" or the learned anchored rule. Chosen once per set; retrained from fixes.
SemanticContext. "Counter edge at wght 700 moves +0.30 px." Rarely edited; lives in the Style screen.
ComponentPart setting. "lock-badge top side holds still at wght 700." Set by the fix tools and marked MANUAL.

Retraining changes only the global and semantic tiers, so a designer's fixes survive every retrain and every style change.

The flow

  1. Set up
  2. Import
  3. Choose style
  4. Generate + gate
  5. Triage
  6. Fix
  7. Teach the rule
  8. Proof
  9. Export
  10. Maintain

Fix loops back to generate on every edit. Teach the rule loops back to generate for the icons nobody fixed. Maintain loops back to import, and after the first release it's where most time goes.

Scope: intent and amount

A fix applies at one location by default, but designers usually make the same call along an axis. Split each fix in two:

  • Intent is which side holds, which end shortens, which part collapses. It carries along its axis by default, and from wght to GRAD, since grade behaves like a small weight change on the outside edge (research 04). It doesn't cross to opsz, which moves counters the other way.
  • Amount is the exact distance. It stays where it was set; other locations take the rule's amount for the pinned intent.

Scope chips above the inspector: This location, Along wght, All locations.

Open decisions

  1. Where the app runs. (a) A local web app, variance serve, over the same Python core the CLI and CI use. (b) A desktop app around that core. (c) A Figma plugin as the main app. Recommended: (a). One core for UI, CLI and CI; files on disk in git. A plugin can't hold the generator and ties the tool to one source app.
  2. Who owns the source after import. (a) Variance adopts it; re-import is a merge. (b) Figma or Illustrator stays the source. Recommended: (a). Settings hang on part names, so (b) breaks whenever someone renames a layer.
  3. Shared parts in v1 or later. Recommended: right after v1. The strongest consistency tool, but part matching across icons isn't researched yet.
  4. Fix scope. Intent carries along its axis and to GRAD; amounts stay put. Recommended as written.
  5. Small sizes. (a) Collapse only. (b) Also alternate constructions: a second source for opsz 20 and below, swapped in by the font's feature variations. Recommended: (a) in v1, (b) later as an explicit feature. (b) is the only way to simplify a shape, but it's a second drawing, which the core principle avoids.
  6. Confidence display. Recommended: three levels with reasons, no percentages.
  7. Reference storage. Recommended: a reference track on each icon, outside the source.
  8. Retraining. Recommended: a button with an impact preview, never automatic.
  9. Revisit "v1 input is skeleton SVG only". Research 05 rebuilt 500 of 500 outlined icons exactly. Recommended: allow outline import in v1, labelled as fitted, with its guesses in the import report.
